LSmusic v1.1.10 使用说明
========================

【应用信息】
- 应用名称：LSmusic
- 版本号：v1.1.1
- 适用平台：飞牛NAS (x86)

【v1.1.1 更新内容】
1. 新增「本地音乐」模块（顶部导航 → 本地音乐）：
   - 选择文件夹（仅已授权文件夹，不可浏览全盘）
   - 扫描本地音乐（自动读标签 / 探测时长码率 / 品质标注）
   - 去重管理（按歌名+歌手分组识别多音质版本，勾选删除非保留版本）
   - 标签管理（写入 标题/歌手/专辑/歌词/封面，支持 MP3 与 FLAC）
   - 批量重命名（默认「歌曲名 - 歌手」，预览冲突后批量执行）
   - 本地播放（支持拖动进度，自动加载歌词与封面）
2. 沿用 v1.1.0 全部能力：
   - 彻底移除 root 权限，授权目录官方机制实时下发
   - 下载目录只可选择已授权文件夹，不可越级返回
   - 下载品质五档：流畅128k / 超高320k / 无损FLAC / 至臻Hi-Res / 母带Master
   - 后端对下载路径强制校验，越权一律拒绝
3. 端口（8899）、应用图标等基础设置与 v1.0.8 完全一致

【核心功能】
1. 第三方音源搜索与播放（解析失败自动重试）
2. 多品质下载：流畅128k / 超高320k / 无损FLAC / 至臻Hi-Res / 母带Master
3. 歌词和封面嵌入音频文件内部（仅NAS下载）
4. 自定义歌曲命名格式（自动记忆上次选择）
5. 下载目录弹窗式选择（仅已授权文件夹，可逐级返回）
6. 下载到NAS或浏览器下载到本地
7. 本地音乐：扫描 / 去重管理 / 批量重命名 / 写歌词封面 / 本地播放

【安装方法】
1. 在飞牛NAS应用中心点击"手动安装"
2. 选择 LSmusic_v1.1.1.fpk 文件进行安装/升级
3. 安装完成后，在桌面或应用中心启动 LSmusic

【首次使用必读：授权文件夹】
1. 打开飞牛桌面 → 应用设置 → 访问权限
2. 点击"添加"，授权 LSmusic 需要访问的文件夹
   （例如「音乐」「LSmusic」等下载目标文件夹）
3. 未授权任何文件夹时，应用内下载会提示目录不可写；
   在飞牛应用设置中完成授权后，回到应用点击「刷新」即可
4. 从旧版本升级时，历史配置会自动迁移；若旧下载目录不在
   新授权范围内，应用会自动回退到第一个已授权文件夹

【使用说明】
1. 首次打开后，在「音源管理」中添加第三方音源（如酷我、酷狗等）
2. 在搜索页输入歌曲名或歌手名进行搜索
3. 点击歌曲可在线播放（主音源解析失败自动重试并智能跨源换源）
4. 点击下载按钮会弹出下载选项：
   - 选择音质（流畅/超高/无损/至臻/母带，显示预计文件大小）
   - 选择是否嵌入歌词和封面
   - 选择下载位置（NAS/本地）
   - 选择文件命名格式（自动记忆上次选择）
   - NAS下载目录为只读展示，统一在「下载设置」中修改
5. 点击"确认下载"开始下载

【修改下载目录】
1. 打开「下载任务」侧边栏
2. 点击右上角齿轮图标进入「下载设置」
3. 点击"更改"按钮浏览已授权文件夹并选择（可逐级进入子文件夹）
4. 点击"保存设置"生效

【命名格式变量】
- {singer} 或 {artist}：歌手名
- {name} 或 {title}：歌曲名
- {album}：专辑名
- {source} 或 {platform}：音源平台

【注意事项】
1. 本地下载不支持嵌入歌词和封面，仅下载原始音频文件
2. 实际可获取的音质取决于第三方音源脚本支持情况，高档位
   （至臻/母带）在源不支持时会自动降级
3. 下载目录仅可选择已授权文件夹；如需新增目录，请先在
   飞牛「应用设置 → 访问权限」中添加
4. 应用以非 root 专用用户运行，任何未授权目录都无法被应用访问
