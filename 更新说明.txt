LSmusic v1.1.1 更新说明
================================================

新增「本地音乐」功能模块（顶部导航 → 本地音乐）

一、选择文件夹
------------------------------------------------
- 点「选择文件夹」浏览并选择要管理的音乐目录
- 仅能选择飞牛「应用设置 → 访问权限」中已授权的文件夹，
  不可越级返回、不可浏览全盘（与下载目录同一套授权机制）
- 已选择目录后点「扫描」即可收集该目录（含子目录）下全部音乐

二、扫描本地音乐
------------------------------------------------
- 自动识别音频文件：MP3 / FLAC / WAV / M4A / AAC / OGG / APE / DSF / DFF
- 自动读取标签（歌名 / 歌手 / 专辑，MP3 优先读 ID3v2 内嵌标签）
- 自动探测时长、码率，并按码率与格式给出品质标签：
  母带 / 至臻 / 无损 / 超高 / 流畅

三、去重管理
------------------------------------------------
- 「去重管理」页按「歌名 + 歌手」自动分组，识别同一歌曲的多音质版本
- 每个版本展示 文件名 / 格式 / 大小 / 时长 / 码率 / 品质
- 勾选不需要的音质版本（第一项默认建议保留最高音质），
  点「删除选中」批量删除；也可用「只留最高音质」一键保留最优版本
- 仅可删除授权目录内且可写的文件，删除前二次确认，删除后不可恢复

四、批量重命名
------------------------------------------------
- 工具栏「批量重命名」：按命名格式批量修改文件名
- 默认格式「歌曲名 - 歌手」，支持变量：
  {name} 歌名 / {singer} 歌手 / {album} 专辑
- 实时预览每个文件的 旧名 → 新名，自动标记：
  已符合格式 / 重名冲突（同目录已存在同名文件）
- 可勾选部分歌曲或一键全选，格式自动记忆上次使用
- 仅重命名文件名，不改动音频内嵌标签；非法字符自动清理，
  扩展名强制与原文件一致；越权与冲突文件后端二次拦截

五、写入歌词 / 封面标签
------------------------------------------------
- 每首歌曲点「标签」图标可打开标签管理：
  - 修改 标题 / 歌手 / 专辑
  - 编辑并写入歌词（LRC 格式，支持从同名 .lrc 或内嵌标签读取）
  - 上传 / 移除封面（写入音频文件内嵌标签）
- 支持 MP3（ID3v2.3）与 FLAC（Vorbis Comment + Picture），
  写入后播放器/其他设备均可见

六、本地播放
------------------------------------------------
- 点歌曲即播，支持拖动进度条（后端流式 Range 播放）
- 自动加载本地歌词（同名 .lrc 或内嵌歌词）与封面
- 播放列表联动：上一首 / 下一首 / 播放模式均可用

七、安全保持不变
------------------------------------------------
- 所有本地音乐接口均做授权目录校验，越权路径一律 403
- 删除与写标签额外要求所在目录可写
- 无 root、专用账号 lsmusic、端口 8899、图标等基础设置不变

─────────────────────────────
v1.1.1 沿用此前全部能力：五档下载品质（含预计文件大小）、
授权目录官方机制实时下发、统一设置入口、命名格式记忆、
音源解析自动重试与智能跨源换源、榜单页精简等。

一、修复：下载一首歌后，搜索结果其他歌曲下载键全部变成 √
------------------------------------------------
- 根因：已下载状态同时用「歌手 - 歌名」宽泛键判断，
  同一首歌的不同平台/专辑版本（kg/wy/tx…）会全部命中，
  导致下载其中一首后整个列表都显示"已在NAS"
- 修复：已下载状态改为按歌曲唯一 id 精确判断（如 kg_xxx / wy_xxx），
  只有真正下载的那一首会显示 √，其他平台版本保持未下载状态
- 说明：1.1.9 及更早版本下载过的歌曲，升级后需重新下载一次
  才会登记为已下载（不会重复占空间，同名文件会覆盖）
